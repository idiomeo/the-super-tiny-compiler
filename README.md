

***欢迎来到超级迷你编译器！***

这是一个用易读的JavaScript编写的现代编译器所有主要组件的极简示例。

通过阅读引导代码，您将了解*大多数*编译器从开始到结束的工作原理。

### [想直接在Github上查看代码？点这里](the-super-tiny-compiler-Chinese.js)

### [您也可以在Gitee上查看本仓库](https://gitee.com/idiomeo/the-super-tiny-compiler)

### 为什么我要关注这个？

这是个合理的问题，大多数人在日常工作中并不需要真正考虑编译器与编译原理。然而，编译器无处不在，您使用的许多工具都基于从编译器借用的概念。

### 但是编译器很可怕！

是的，确实如此。但这是他们的错（编写编译原理教材的人），正如应试教育的教材毁掉了孩子们对数学产生热爱的可能一样，他们把一个相当简单的东西变得如此可怕，以至于大多数人认为这是只有最极客的人才能理解的完全不可接近的东西。

### 好的，那么我从哪里开始？

请转到[the-super-tiny-compiler-Chinese.js](the-super-tiny-compiler-Chinese.js)文件。
